### 정하지 않은 것 <Status type="미결정" />

- 저장소 구조: 폴더 분리 유지 / Turborepo로 apps·packages 구성 → FE·BE 협의 후 전달
- 회차 구분 기준([SEC-16](../policy/session-split)): 몇 글자마다 나눌지, 단원을 어떻게 알아볼지 → 이번 주말 전 확정 목표, 아이디어를 댓글로 받음
- 퀴즈 진입([QIZ-05](../policy/quiz)): 필사를 마치면 퀴즈로 갈지 묻고 동의하면 시작 → 시안 제작 후 확인
- 이벤트 로그 수집 시점 → 결과 확인 후 기록
