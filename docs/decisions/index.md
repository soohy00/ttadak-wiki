- 백엔드 로컬 DB를 Docker로 띄울지 → 12/1 회의
- FE 배포 위치: 4차 "초기 Vercel"과 직군 회의 "AWS 운영 환경 1개"가 달라 확인 중. 1사이클 중 PD·PM이 볼 미리 보기 주소도 함께 확인
- 회차 구분 기준([SEC-16](../policy/session-split)): 몇 글자마다 나눌지, 단원을 어떻게 알아볼지 → 이번 주말 전 확정 목표, 아이디어를 댓글로 받음
- 퀴즈 진입([QIZ-05](../policy/quiz)): 필사를 마치면 퀴즈로 갈지 묻고 동의하면 시작 → 시안 제작 후 확인
- 이벤트 로그 수집 시점 → 결과 확인 후 기록
- 다음 회의(12/1(화))로 넘김: 퀴즈 1사이클 범위(QIZ-03), 한 줄 문구, 코드 리뷰 승인 기준, DB 마이그레이션 방식, 공유 문서 위치, 위키 질문·피드백 방법, 정책 결정 범위, 시안 담당·투표 방법·마감

## 기획 시안 팀원 피드백 반영 (2026-11-25(수))

4차 회의에서 합본(카드 1–17)에 남긴 노션 댓글을 정리해 반영했습니다. 각 댓글에 답변을 남겼습니다.

| 카드 | 반영 | 정책 |
| --- | --- | --- |
| 1 자료 넣기 | 잘 나오는 자료 예시, 치기 어려운 기호는 자동으로 넘김 | UPL-18, TRN-20 |
| 3 회차 나누는 중 | 나누는 방법 고르기(나누지 않기·파일마다 1회차), 문단 글자 직접 수정, 회차 미리 보기·PDF 쪽수 | SEC-17·18·19, UPL-10 |
| 5 회차 조정 | 시안 D(원문에서 나누고 목록에서 순서 조정) 추가 | SEC-04 |
| 7 회차 목록 | 진행률 % | TRN-21 |
| 8 따라 쓰기 | 진행 막대로 문장 이동·건너뛰기 | TRN-22 |
| 9 빈칸 입력 | 문장 전체 다시 쓰기(C) 추천, 빈칸만 채우기는 퀴즈 후보로, 초성 힌트 | TRN-16·23, QIZ-04 |
| 10 백지 입력 | 원문 잠깐 보기 | TRN-24 |
| 11 백지 비교 | 띄어쓰기·문장부호는 약하게 표시, 사용자가 '맞은 걸로' 표시 | TRN-25 |
| 12 단계 완료 | 걸린 시간·글자/분 숨김, 글자 수 표시 | TRN-15 |
| 14 샘플 체험 | 필사만 유지(답변) | ACC-06 |

- 레이아웃 의견(반반·중앙·위아래, 내 입력 위치, 칸 크기)은 디자인 파트에 넘김 (4차 결정)
- 2사이클 후보: 챗봇으로 회차 고치기, 백지 입력 방식 사용자 선택, 의미가 같은 단어 AI 판별, 채점 '관대하게/정확하게' 옵션, 자료 정리 매뉴얼·데이터 형식
