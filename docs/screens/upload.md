## 사용자 흐름

1. 자료 넣기 화면에서 텍스트를 붙여넣거나 파일을 고른다.
2. 업로드를 누르면 형식·용량을 검사한다. (UPL-05)
3. 통과하면 텍스트를 추출하고, 회차 구분 화면으로 이동한다. (UPL-07)
