# 진입 화면

<div class="doc-info">
<span>화면 ID: SCR-ENT</span>
<span>정책: <a href="../policy/account">ACC 계정·설정 정책</a> (ACC-01)</span>
<span>와이어프레임: 1920×1080 설계서 보드 (낮은 완성도, 2026-11-23)</span>
</div>

## 사용자 흐름

1. 로그인하지 않은 사람은 0.1 시작 화면을 본다.
2. "샘플로 체험하기"를 누르면 0.2 샘플 체험에서 필사 화면(4.1–4.6)을 샘플 자료로 써 본다. 기록은 저장하지 않는다.
3. 저장하거나 내 자료를 넣으려면 [로그인](./account)한다.

## 0.1 시작 화면 · SCR-ENT-01

<a href="/ttadak-wiki/screens/new-0-1.png" target="_blank"><img src="/screens/new-0-1.png" alt="0.1 시작 화면"></a>
<p class="wf-cap">1920×1080 화면 설계서 보드. 이미지를 누르면 원본 크기로 열려요.</p>

| 번호 | 요소 | 종류 | 설명 |
| --- | --- | --- | --- |
| 1 | 로그인 | Button | 로그인하지 않은 사용자에게만 노출됩니다. 상태: default, hover, pressed → 클릭할 경우 0.3 로그인 화면으로 이동합니다. |
| 2 | 핵심 문구 | Text | 서비스가 하는 일을 한 문장으로 보여 줍니다. 문구는 4차 회의의 한 줄 문구 결정을 따릅니다. |
| 3 | 샘플로 체험하기 | Button | 화면의 주 버튼입니다. 로그인 없이 샘플 자료로 필사를 체험합니다(ACC-01). 상태: default, hover, pressed → 클릭할 경우 0.2 샘플 체험 화면으로 이동합니다. |
| 4 | 내 자료로 시작하기 | Button | 자료를 넣으려면 로그인이 필요합니다(UPL-14). 상태: default, hover, pressed → 클릭할 경우 0.3 로그인 화면으로 이동하고, 로그인 후 2.1 자료 넣기로 이동합니다. |
| 5 | 미리 보기 | Image | 필사 화면(4.2) 모습을 보여 주는 이미지 자리입니다. 움직임 여부는 디자인에서 정합니다. |
| 6 | 사용 방법 | Card | 3단계를 카드 3개로 설명합니다. 누를 수 없는 안내용 카드입니다. |

- 정할 것: 이 화면이 필요한지(샘플 체험으로 바로 보낼지), 핵심 문구. 관련 정책: ACC-01, UPL-14

## 0.2 샘플 체험 · SCR-ENT-02

<a href="/ttadak-wiki/screens/new-0-2.png" target="_blank"><img src="/screens/new-0-2.png" alt="0.2 샘플 체험"></a>
<p class="wf-cap">1920×1080 화면 설계서 보드. 이미지를 누르면 원본 크기로 열려요.</p>

| 번호 | 요소 | 종류 | 설명 |
| --- | --- | --- | --- |
| 1 | 체험 안내 띠 | Banner | 샘플 체험 중임을 알리는 띠입니다. 화면을 내려도 상단에 고정됩니다. 기록이 저장되지 않는다는 점을 함께 알립니다. → 버튼을 클릭할 경우 0.3 로그인 화면으로 이동합니다. |
| 2 | 샘플 자료 이름 | Text | 샘플 세트의 이름과 회차 수, 글자 수, 예상 시간입니다. 샘플 내용은 [미결정]입니다. |
| 3 | 회차 줄 | List | 4.1 회차 목록과 같은 부품입니다. 칩을 눌러 원하는 단계로 바로 갈 수 있습니다. 상태: 시작 전만 존재 (기록 저장 안 함) → 클릭할 경우 4.2 따라 쓰기 화면으로 이동합니다(샘플 데이터). |
| 4 | 로그인 유도 | Banner | 단계를 하나 마치면 4.6 단계 완료 화면에 로그인 버튼을 추가로 노출합니다. → 로그인하면 1.1 내 자료로 이동합니다. 샘플 기록은 옮기지 않습니다. |

- 정할 것: 샘플 세트 내용(자료·회차 수), 로그인 유도 시점. 관련 정책: ACC-01

## 정할 것

- 0.1 시작 화면이 필요한지 (샘플 체험으로 바로 보낼지)
- 샘플 세트 내용, 로그인을 유도하는 시점
