## 사용자 흐름

1. 추출이 끝나면 AI가 나눈 회차 목록을 본다. (SEC-01)
2. 필요하면 회차의 순서·내용을 조정한다. (SEC-02)
3. 확정하면 첫 회차의 필사로 이동한다. (SEC-03)
