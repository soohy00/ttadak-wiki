## 사용자 흐름

1. 로그인하면 1.1 내 자료를 본다. 자료가 없으면 빈 화면(1.1.2)에서 자료 넣기로 간다.
2. 자료 카드를 누르면 [회차 목록](./transcription)으로 가서 하던 문장부터 이어서 한다.

## 1.1.1 내 자료 · 자료 있음 · SCR-HOM-01

<a href="/ttadak-wiki/screens/new-1-1-1.png" target="_blank"><img src="/screens/new-1-1-1.png" alt="1.1.1 내 자료 · 자료 있음"></a>
<p class="wf-cap">1920×1080 화면 설계서 보드. 이미지를 누르면 원본 크기로 열려요.</p>

| 번호 | 요소 | 종류 | 설명 |
| --- | --- | --- | --- |
| 1 | 상단 바 · 자료 넣기 | Button | 모든 홈 화면에서 같은 자리에 있습니다. 내비게이션 형태는 4차 회의 투표로 정합니다. → 클릭할 경우 2.1 자료 넣기 화면으로 이동합니다. |
| 2 | 페이지 제목 | Text | 자료 개수와 정렬 기준(최근 학습 순)을 함께 보여 줍니다. |
| 3 | 자료 카드 | Card | 자료 이름, 회차 수·글자 수, 진행 막대, 완료한 회차 수, 마지막 학습 시간입니다. 버튼은 진행 상태에 따라 시작 / 이어서 하기 / 다시 하기로 바뀝니다. 상태: default, hover → 카드나 버튼을 클릭할 경우 4.1 회차 목록으로 이동합니다(이어서 하기는 마지막 문장부터, TRN-12). |
| 4 | 더보기 메뉴 | Menu | 이름 바꾸기 / 삭제 2개입니다. → 삭제를 클릭할 경우 "자료와 필사 기록이 지워져요" 확인 모달을 띄웁니다. |
| 5 | 처리 중인 자료 | Card | 회차를 나누는 중이거나 실패한 자료입니다. 버튼은 disabled이며, 끝나면 자동으로 일반 카드로 바뀝니다. 상태: 나누는 중, 나누기 실패(→ 3.3) |

- 새로 생긴 규칙(검토 중): 자료 이름 바꾸기·삭제, 최근 학습 순 정렬. 위키 정책서에 추가 예정

## 1.1.2 내 자료 · 빈 화면 · SCR-HOM-01

<a href="/ttadak-wiki/screens/new-1-1-2.png" target="_blank"><img src="/screens/new-1-1-2.png" alt="1.1.2 내 자료 · 빈 화면"></a>
<p class="wf-cap">1920×1080 화면 설계서 보드. 이미지를 누르면 원본 크기로 열려요.</p>

| 번호 | 요소 | 종류 | 설명 |
| --- | --- | --- | --- |
| 1 | 자료 넣기 | Button | 빈 화면의 주 버튼입니다. 가입 직후 처음 보는 화면입니다. 상태: default, hover, pressed → 클릭할 경우 2.1 자료 넣기 화면으로 이동합니다. |
| 2 | 샘플로 먼저 체험하기 | Text Button | 로그인한 사용자도 샘플을 체험할 수 있습니다. 이때는 기록을 저장합니다 [검토 중]. → 클릭할 경우 0.2 샘플 체험 화면(안내 띠 없이)으로 이동합니다. |

- 관련 정책: ACC-01, UPL-14

## 정할 것

- 자료 이름 바꾸기·삭제, 최근 학습 순 정렬 → [HOM 정책서](../policy/home) HOM-02·04·05 (검토 중)
- 자료 개수 상한, 휴지통, 내비게이션 형태 → HOM-07–10 (미결정)
