# 필사

회차 하나를 따라 쓰기 → 빈칸 → 백지 3단계로 타자 필사하는 핵심 기능입니다.

::: dev
## 의도

- 손 필사보다 빠르게 범위 전체를 반복하게 합니다.
- 단계를 올릴수록 원문을 덜 보여 주어, 마지막 백지 단계에서 스스로 점검하게 합니다.

## 정책

| 항목 | 규칙 | 상태 |
| --- | --- | --- |
| 필사 방식 | 웹에서 타자로 필사 | <Status type="확정" /> |
| 단계 | 따라 쓰기 → 빈칸 → 백지 3단계 모두 1사이클 도입 | <Status type="확정" /> |
| 한 번에 보여 주는 분량 | 문장 1개 / 여러 문장, 시안·투표로 결정 | <Status type="미결정" /> |
| 빈칸 만드는 기준 | 어절(띄어쓰기) 단위로 비우기 (팀원 제안) | |
| 백지 단계 확인 방식 | 자동 채점 대신 원문과 나란히 보는 자가 확인 (팀원 제안) | |
| 완료 기록 | 회차·단계별 완료를 저장 | |

## 단계별 동작

| 단계 | 보여 주는 것 | 사용자가 하는 것 |
| --- | --- | --- |
| 따라 쓰기 | 원문 전체 | 원문을 보며 그대로 입력 |
| 빈칸 | 일부를 비운 원문 | 빈칸을 채워 입력 |
| 백지 | 원문 없음 | 처음부터 입력한 뒤 원문과 비교 |

## 사용자 흐름

회차 선택 → 따라 쓰기 → 빈칸 → 백지 → 원문과 비교 → 퀴즈로 이동

## 와이어프레임

화면 분량(문장 1개 / 여러 문장) 시안 2개 이상 작성 후 투표 <Status type="미결정" />

## 화면 설계서 (초안)

| 요소 | 액션 | 상태 |
| --- | --- | --- |
| 단계 표시 | 현재 단계 표시, 이전 단계로 이동 | 따라 쓰기 / 빈칸 / 백지 |
| 원문 영역 | 단계에 따라 원문·빈칸·가림 표시 | 전체 / 빈칸 / 가림 |
| 입력 영역 | 타자 입력 | 입력 전 / 입력 중 / 완료 |
| 비교 보기(백지) | 원문과 입력을 나란히 표시 | 숨김 / 표시 |
| 다음 버튼 | 다음 문장·단계로 이동 | 비활성 / 활성 |
