# 자료 업로드 <Status type="초안" />

사용자가 외울 자료를 따닥에 넣는 단계입니다. 1사이클은 글자로 된 자료만 받습니다.

::: dev
## 의도

- 1사이클은 업로드한 자료에서 **필사할 텍스트를 얼마나 정확히 뽑아내는지** 검증하는 데 집중합니다.
- 사진·스캔본처럼 글자 인식(OCR)이 필요한 자료는 받지 않고, 2단계 웹 고도화에서 다룹니다.

## 정책

| 항목 | 규칙 | 상태 |
| --- | --- | --- |
| 받는 자료 | 텍스트 붙여넣기, txt·md·docx 파일, 글자로 된 PDF | <Status type="확정" /> |
| 받지 않는 자료 | 스캔·사진 PDF, 이미지, PPT 파일, URL | <Status type="확정" /> |
| 용량 한도 | 1회 20MB | <Status type="확정" /> |
| 하루 업로드 한도 | 없음 (1일 한도는 3차 회의에서 채택하지 않음) | <Status type="확정" /> |
| PPT 자료 | PDF로 저장해 올리도록 안내 (팀원 제안) | <Status type="초안" /> |

## 동작 규칙

1. 사용자가 텍스트를 붙여넣거나 파일을 고른다.
2. 형식과 용량을 먼저 검사한다. 통과하지 못하면 이유를 알려 주고 업로드하지 않는다.
3. 파일에서 텍스트를 추출한다.
4. 추출한 텍스트를 [회차 구분](./session-split)으로 넘긴다.

## 예외 처리

| 상황 | 처리 | 상태 |
| --- | --- | --- |
| 20MB 초과 | 업로드 막고 한도 안내 | <Status type="초안" /> |
| 받지 않는 형식 | 업로드 막고 받는 형식 안내 | <Status type="초안" /> |
| PDF에서 글자가 추출되지 않음(스캔본) | "글자로 된 PDF만 올릴 수 있어요" 안내 [문구: ?] | <Status type="초안" /> |
| 추출 중 실패 | 다시 시도 안내 [재시도 방식: ?] | <Status type="미결정" /> |
:::

## 사용자 흐름

자료 넣기 화면 → 텍스트 붙여넣기 또는 파일 선택 → 검사 → 추출 중 → 회차 구분 확인 화면
