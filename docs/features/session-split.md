# 회차 구분

업로드한 자료를 한 번에 공부할 단위(회차)로 나누는 단계입니다.

::: dev
## 의도

- 무엇을 어떤 순서로 외울지 정리하는 시간을 줄입니다.
- AI가 먼저 나누고, 사용자가 고쳐서 바로 필사를 시작할 수 있게 합니다.

## 정책

| 항목 | 규칙 | 상태 |
| --- | --- | --- |
| 구분 방식 | AI가 단원·주제 기준으로 구분 | <Status type="확정" /> |
| 사용자 수정 | 회차의 순서와 내용을 사용자가 조정 | <Status type="확정" /> |
| 수정 방법 | 시안·투표로 결정 | <Status type="미결정" /> |
| 단계별 회차 표시 | 업로드·필사·퀴즈 단계에서 회차를 보여 주는 방식은 시안·투표로 결정 | <Status type="미결정" /> |
| AI 모델·API | 4차 회의에서 결정 | <Status type="미결정" /> |

## 동작 규칙

1. 추출한 텍스트를 AI에 보내 회차 목록(제목, 범위)을 받는다.
2. 회차 목록을 사용자에게 보여 준다.
3. 사용자가 순서·내용을 조정한다. [조정 방법: 시안·투표 후 작성]
4. 사용자가 확정하면 회차별로 [필사](./transcription)를 시작할 수 있다.
