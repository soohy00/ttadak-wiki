# 퀴즈

필사로 외운 내용을 가볍게 확인하는 단계입니다.

::: dev
## 의도

- 필사한 내용을 퀴즈로 확인해, 외웠다는 것을 사용자가 스스로 증명하는 경험을 줍니다.

## 정책

| 항목 | 규칙 | 상태 |
| --- | --- | --- |
| 도입 시점 | 1사이클 도입 | <Status type="확정" /> |
| 1사이클 범위 | 빈칸 퀴즈만 / 단답 등 AI 생성 퀴즈까지 | <Status type="미결정" /> |
| 문제 형식 | 선택지 / 빈칸 타자 입력 / 빈칸 선택, 시안·투표로 결정 | <Status type="미결정" /> |
| 출제 범위 | 회차 단위 [ ? ] | |

## 미결정

- 4차 회의(11/24(화))에서 1사이클 범위를 정한 뒤 동작 규칙을 씁니다.
:::

::: design
## 사용자 흐름

필사 완료 → 퀴즈 시작 → 문제 풀이 → 결과 확인

## 와이어프레임

문제 형식 시안 작성 후 투표 <Status type="미결정" />

## 화면 설계서

문제 형식이 정해지면 작성 <Status type="미결정" />
:::
