# 문제 정의·페르소나

근거: 팀원 대상 "내가 따닥을 쓴다면" 응답 8명, 3차 회의 결정(2026-11-21). 4차 회의(11/24(화)) 전까지 검토합니다.

## 문제 문장

::: tip
마감 직전에 몰아서 외워야 하는 학습자는 흩어진 자료를 정리하는 데 시간을 써서, 정작 외우고 점검할 시간이 부족하다. 필사로 외우고 싶어도 손 필사는 느리고, 무엇을 못 외웠는지 스스로 확인하기 어렵다.
:::

## 문제 상황

- 마감 직전 집중 학습은 기간이 짧음: 전날~4일 전, 1–3회, 회당 30분–3시간
- 자료 형태가 다양함(응답 8명 중): 수업 PPT·PDF 4명, 판서·풀이 사진·책 캡처본 3명, 족보·예상 답안 3명, 발표·면접 스크립트 3명
- 손 필사는 느려 범위 전체를 반복하기 어려움
- 혼자 백지 테스트를 하면 취약한 부분과 다음 학습 범위를 파악하기 어려움

| 원인 | 결과 | 영향 |
| --- | --- | --- |
| 자료가 많고 과목·형식별로 흩어짐 | 무엇을 어떤 순서로 외울지 정리하는 데 시간 소요 | 암기·점검 시간 부족 |
| 손 필사 속도가 느림 | 범위 전체를 반복하지 못함 | 1–3회 학습 안에 범위를 끝내지 못함 |
| 혼자 백지로 점검 | 틀린 곳·빠진 곳을 놓침 | 다음에 볼 곳을 모르고 시험에 들어감 |

## 페르소나

응답 사례를 묶어 만든 가상 인물입니다.

### A. 시험 직전에 몰아서 외우는 대학생 (1사이클 주 대상)

| 항목 | 내용 |
| --- | --- |
| 상황 | 중간·기말고사 2~4일 전부터 1–3회, 회당 2–3시간씩 몰아서 공부 |
| 공부하는 것 | 암기 과목, 서술형 예상 문제, 족보 문제·풀이 |
| 업로드 자료 | 수업 PPT·PDF, 강의 녹음을 바꾼 텍스트, 족보·예상 답안 (풀이 사진은 2단계 OCR 이후) |
| 목표 | 시험 범위를 빠르게 한 바퀴 돌고, 시험 전날 백지로 점검 |
| 불편한 점 | 자료가 흩어져 정리에 시간이 오래 걸림. 손 필사로는 범위를 다 쓰지 못함. 혼자 백지 테스트를 해도 틀린 곳을 놓침 |
| 따닥 사용 흐름 | 텍스트 PDF 업로드 → AI 회차 구분 확인·순서 조정 → 따라 쓰기 → 빈칸 → 백지 → 퀴즈 |
| 근거 | 마감 직전 집중 학습 유형 5명 |

### B. 발표·면접 직전에 스크립트를 외우는 준비생 (1사이클 대상)

| 항목 | 내용 |
| --- | --- |
| 상황 | 발표·면접 1–2일 전, 하루 30분–1시간 |
| 공부하는 것 | 직접 쓴 발표·면접 스크립트, 예상 질문 답변 |
| 업로드 자료 | 스크립트 붙여넣기, MD·노션 정리 |
| 목표 | 원문을 보지 않고 처음부터 끝까지 말할 수 있을 만큼 외우기 |
| 불편한 점 | 읽기만으로는 어디가 빠졌는지 모름. 원문과 하나씩 비교하기 번거로움 |
| 따닥 사용 흐름 | 스크립트 붙여넣기 → 따라 쓰기 → 원문을 가리고 백지 재작성 → 원문과 비교 → 퀴즈 |
| 근거 | 발표·면접 스크립트 사례 4명 |
