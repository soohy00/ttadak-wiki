# 세부 경험 결정 원칙 <Status type="확정" />

::: warning 원칙
- 다른 분야 서비스에서도 보편적으로 같은 방향으로 가는 경험(로그인 플랫폼, 로그인 과정, 유저 설정 등)은 **그 방향을 따릅니다.**
- 보편적인 방향이 없는 경험은 **시안을 여러 개 만들어 팀원 투표로 정합니다.**
:::

## 항목별 분류

PM 초안입니다. 4차 회의(11/24(화))에서 확정합니다.

| 경험 | 정할 내용 | 보편 패턴 | 진행 방식 |
| --- | --- | --- | --- |
| 로그인 플랫폼 | 소셜 로그인 제공사 | 있음 | 확정: Google만(ACC-03) |
| 로그인·회원가입 과정 | 단계, 입력 항목 | 있음 | 보편 패턴 따름 |
| 유저 설정 | 메뉴 구성 | 있음 | 보편 패턴 따름 |
| 페이지 구성·내비게이션 | 탭바 / 사이드바 / 상단 내비게이션 | 일부 있음 | 웹 기준 확인 후, 갈리면 시안·투표 |
| 필사 화면 분량 | 한 번에 문장 1개 / 여러 문장 | 없음 | 시안·투표 |
| 퀴즈 형식 | 선택지 / 빈칸 타자 입력 / 빈칸 선택 | 없음 | 시안·투표 |
| 단계별 회차 반영 | 업로드·필사·퀴즈 단계에서 회차를 보여 주는 방식 | 없음 | 시안·투표 |
| 회차 개인 수정 | AI 구분 결과의 순서·내용을 고치는 방법 | 없음 | 시안·투표 |

## 시안·투표 진행 <Status type="미결정" />

- 시안 담당, 항목별 시안 수, 투표 방법, 투표 마감은 4차 회의에서 정합니다.
- 투표 결과는 이 페이지와 각 기능 페이지에 옮기고 <Status type="확정" /> 으로 바꿉니다.
