# 서비스 개요

**따닥**은 공부 자료를 올리면 회차로 나눠 주고, 따라 쓰기·빈칸·백지 필사와 퀴즈로 외우게 돕는 웹 서비스입니다.

## 서비스 단계 <Status type="확정" />

| 단계 | 플랫폼 | 내용 |
| --- | --- | --- |
| 1단계 MVP | 웹 | 타자 필사 (1순위) |
| 2단계 웹 고도화 | 웹 | 게이미피케이션, OCR 등 웹 서비스 품질 향상 |
| 3단계 | 패드 앱 | 웹 완성 후 패드 앱으로 확장 |

## 1사이클 범위 <Status type="확정" />

- 기간: 2026-11-21(토)부터 3주
- 대상: 시험·발표·면접 직전에 몰아서 외우는 사람 ([문제 정의·페르소나](./problem))
- 핵심 경험: 필사 + AI 보조

| 항목 | 결정 | 상세 |
| --- | --- | --- |
| 자료 업로드 | 텍스트 + 텍스트 PDF, 1회 20MB | [UPL 정책](../policy/upload) · [화면](../screens/upload) |
| 회차 구분 | AI 구분 기본 + 사용자가 순서·내용 조정 | [SEC 정책](../policy/session-split) · [화면](../screens/session-split) |
| 필사 | 따라 쓰기 → 빈칸 → 백지 | [TRN 정책](../policy/transcription) · [화면](../screens/transcription) |
| 퀴즈 | 1사이클 도입 | [QIZ 정책](../policy/quiz) · [화면](../screens/quiz) |
| 게이미피케이션 | 2단계 웹 고도화에서 도입 | — |

## 1사이클에서 하지 않는 것

- 사진·스캔 PDF(OCR), PPT 파일 직접 업로드, URL 본문 추출 → 2단계 이후
- 경험치·레벨·퀘스트 → 2단계
- 패드 앱 → 3단계

## 아직 정하지 않은 것 <Status type="미결정" />

4차 회의(11/24(화))에서 정합니다.

- 기술 스택: FE 프레임워크, 데이터베이스, FE 배포, AI 모델·API
- 이벤트 로그 도입 시점
- 퀴즈 1사이클 범위
