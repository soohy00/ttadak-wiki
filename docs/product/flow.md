## 전체 흐름도

![따닥 1사이클 전체 흐름도](/design/flow.png)

- **처음 온 사람**: 0.1 시작 화면 → 0.2 샘플 세트로 필사 체험 → 저장하려면 0.3 로그인 → 1.1 내 자료
- **자료를 넣는 사람**: 1.1 → 2.1 자료 넣기 → 3.1 회차 나누는 중 → 3.2 회차 확인·조정 → 4.1 회차 목록
- **필사하는 사람**: 4.1 → 4.2 따라 쓰기 → 4.3 빈칸 → 4.4 백지 → 4.5 백지 비교 → 5.1 퀴즈 → 다음 회차
- **다시 온 사람**: 0.3 로그인(또는 로그인 유지) → 1.1 내 자료 → 자료 고르기 → 4.1 → 이어서 하기

## 흐름에서 정할 것

- **0.1 시작 화면이 필요한지**: 로그인하지 않은 사람이 처음 보는 화면. 샘플 체험(ACC-01)으로 바로 보낼지, 서비스 소개를 한 장 둘지
- ~~로그인을 요구하는 시점~~ → 확정: 샘플 체험(필사)을 마쳤을 때와 자료 넣기를 누를 때 ([ACC-06](../policy/account), UPL-14)
- **샘플 세트 내용**: 어떤 자료로 몇 회차를 체험하게 할지
- **내비게이션 형태**: 상단 / 사이드바 (시안·투표, 일정 미정)
- **1280보다 좁은 화면**: 1사이클에서 다룰지
