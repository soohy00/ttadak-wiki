# TRN 필사 정책

<div class="doc-info">
<span>정책 ID: TRN</span>
<span>화면: <a href="../screens/transcription">필사 화면</a></span>
<span>근거: <a href="../decisions/">3차 회의</a></span>
</div>

## 목적

회차 하나를 웹에서 타자로 필사하며 외우게 합니다. 손 필사보다 빠르게 범위 전체를 반복하고, 단계를 올릴수록 원문을 덜 보여 주어 마지막에 스스로 점검하게 합니다.

## 용어

| 단계 | 보여 주는 것 | 사용자가 하는 것 |
| --- | --- | --- |
| 따라 쓰기 | 원문 전체 | 원문을 보며 그대로 입력 |
| 빈칸 | 일부를 비운 원문 | 빈칸을 채워 입력 |
| 백지 | 원문 없음 | 처음부터 입력한 뒤 원문과 비교 |

- **문장**: 필사 화면에 한 번에 보여 주는 단위(TRN-06). 회차를 확정할 때 회차 원문을 문장으로 나눠 저장함(TRN-08)
- **어절**: 띄어쓰기로 나뉘는 단위. 빈칸은 어절 단위로 비움(TRN-03)

## 정책

### 확정

<div class="policy">

- **TRN-01** 필사는 웹에서 타자로 입력한다.
- **TRN-02** 따라 쓰기 → 빈칸 → 백지 3단계를 모두 1사이클에 제공한다.
- **TRN-06** 한 번에 문장 1개씩 보여 준다.
- **TRN-07** 틀린 글자는 빨간색으로 표시한다. 오타가 있으면 다음으로 넘어가지 않는다. 넘어가려 하면 입력 영역을 좌우로 흔드는 '삐빅' 모션으로 수정을 알린다.

</div>

### 검토 중

<div class="policy">

- **TRN-03** 빈칸은 어절(띄어쓰기) 단위로 비운다. (팀원 제안)
- **TRN-04** 백지 단계는 자동 채점 대신, 입력과 원문을 나란히 보여 주는 자가 확인으로 한다. (팀원 제안)
- **TRN-05** 회차·단계별 완료 여부를 저장한다.
- **TRN-08** 회차를 확정하면(SEC-03) 회차 원문을 문장으로 나눠 저장한다. 마침표·물음표·느낌표·줄바꿈에서 나누고, 번호·기호(1. ① - •)로 시작하는 줄은 그 줄을 한 문장으로 본다. [N자: 개발 확인]보다 긴 문장은 쉼표에서 한 번 더 나눈다.
- **TRN-09** 입력은 원문과 글자 단위로 비교한다. 띄어쓰기·문장부호도 원문과 같아야 한다. 연속 공백은 하나로 보고, 문장 끝 공백은 무시한다. 한글을 조합하는 중인 마지막 글자는 오타로 보지 않는다.
- **TRN-10** 원문과 똑같이 입력한 뒤 Enter를 누르면 다음 문장으로 넘어간다. Shift+Enter나 버튼으로 이전 문장을 다시 볼 수 있다.
- **TRN-11** 한 회차의 모든 문장을 마치면 그 단계가 완료된다. 단계는 순서대로 권하지만 잠그지 않는다. 마감 직전 사용자는 바로 백지로 갈 수 있다.
- **TRN-12** 필사 중 나가면 회차·단계·마지막 문장 위치를 저장하고, 다시 들어오면 그 문장부터 이어서 한다.
- **TRN-13** 백지 단계에는 TRN-07(오타 시 진행 막기)을 적용하지 않는다. 원문을 보여 줄 수 없으므로, 다 쓴 뒤 비교 화면(TRN-04)에서 확인한다.
- **TRN-14** 백지 비교 화면은 입력과 원문을 나란히 두고, 다른 어절에 밑줄을 긋는다. 점수나 정답률은 보여 주지 않는다.
- **TRN-15** 단계를 마치면 걸린 시간과 문장 수만 보여 주고 다음 단계로 안내한다. 경험치·레벨·연속 기록은 두지 않는다(게이미피케이션은 2단계).

</div>

### 미결정

<div class="policy">

- **TRN-16** 빈칸 입력 방식 → 시안·투표 (A 빈칸 자리에 바로 입력 / B 아래 칸에 빈칸 단어만 입력 / C 문장 전체를 다시 입력)
- **TRN-17** 백지 입력 단위 → 시안·투표 (A 문장 하나씩 / B 회차 전체를 한 번에)
- **TRN-18** 비울 어절 고르는 법(무작위 / AI가 핵심어 선택)과 비율. AI로 고르면 4차 회의에서 정하는 AI 모델을 함께 씀
- **TRN-19** 필사 화면에서 회차를 보여 주는 방식 → SEC-05와 함께 시안·투표

</div>

## 처리 흐름

| 순서 | 상태 | 하는 일 | 다음 상태 | 정책 |
| --- | --- | --- | --- | --- |
| 1 | 회차 확정 | 회차 원문을 문장으로 나눠 저장, 빈칸 어절 미리 정함 | 시작 전 | SEC-03, TRN-08·18 |
| 2 | 시작 전 | 회차 목록에서 회차·단계를 고름 | 진행 중 | TRN-11 |
| 3 | 진행 중 | 문장 1개씩 입력, 비교, Enter로 다음 문장. 나가면 위치 저장 | 마지막 문장 끝 → 단계 완료 | TRN-06·07·09·10·12 |
| 4 | 단계 완료 | 걸린 시간·문장 수 표시. 백지면 비교 화면으로 | 다음 단계 시작 전 / 백지 비교 | TRN-05·15 |
| 5 | 백지 비교 | 입력과 원문을 나란히 보고 다른 어절 확인 | 퀴즈(QIZ) / 백지 다시 / 회차 목록 | TRN-04·14 |

## 저장하는 정보

개발 참고용입니다. 이름은 바뀔 수 있습니다.

| 대상 | 정보 | 비고 |
| --- | --- | --- |
| 문장 | 회차 안 순번, 텍스트, 빈칸 어절 위치 | 회차 확정 때 만듦(TRN-08) |
| 단계 기록 | 회차, 단계, 상태(시작 전·진행 중·완료), 마지막 문장 순번, 시작·완료 시각 | 이어서 하기(TRN-12), 완료 표시(TRN-05) |
| 백지 입력 | 회차, 입력한 텍스트, 저장 시각 | 비교 화면을 다시 볼 때 씀. 1사이클은 마지막 1개만 |

- 오타 횟수·키 입력 같은 이벤트 로그는 1사이클에 모으지 않습니다(4차 회의에서 확정).

## 예외·에러 메시지

| 상황 | 메시지 (초안) | 정책 |
| --- | --- | --- |
| 오타가 있는 채로 Enter | (문구 없음, 입력 영역 흔들림) | TRN-07 |
| 이어서 하기 | 지난번 3번째 문장부터 이어서 할게요. | TRN-12 |
| 앞 단계를 건너뜀 | 빈칸 단계를 아직 안 했어요. 그래도 백지로 갈까요? | TRN-11 |
| 백지 중 나가기 | 지금까지 쓴 내용은 저장돼요. | TRN-12 |
