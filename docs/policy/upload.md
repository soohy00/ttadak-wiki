## 목적

사용자가 외울 자료를 따닥에 넣는 단계입니다. 1사이클은 업로드한 자료에서 **필사할 텍스트를 얼마나 정확히 뽑아내는지** 검증하는 데 집중하므로, 글자로 된 자료만 받습니다.

## 용어

- **글자로 된 PDF**: 글자를 선택·복사할 수 있는 PDF. 스캔하거나 사진으로 만든 PDF는 해당하지 않음
- **자료**: 사용자가 한 번에 올린 파일 1개 또는 붙여넣은 텍스트 1건. 회차 구분([SEC](./session-split))의 단위
- **문단**: 추출한 텍스트를 빈 줄 기준으로 나눈 단위. 회차는 문단을 묶어 만듦

## 정책

### 확정

<div class="policy">

- **UPL-01** 텍스트 붙여넣기, txt·md·docx 파일, 글자로 된 PDF를 받는다.
- **UPL-02** 스캔·사진 PDF, 이미지, PPT 파일, URL은 받지 않는다. 사진·스캔 자료(OCR)는 2단계 웹 고도화에서 다룬다.
- **UPL-03** 한 번에 올릴 수 있는 용량은 20MB까지다.
- **UPL-04** 하루 업로드 한도는 두지 않는다.
- **UPL-17** hwp·hwpx(한글) 파일은 1사이클에서 받지 않는다. PPT와 같이 PDF로 저장해 올리도록 안내한다. (11/23 PM 결정)

</div>

### 검토 중

<div class="policy">

- **UPL-05** 업로드하면 형식(UPL-01·02)과 용량(UPL-03)을 먼저 검사하고, 통과한 경우에만 텍스트를 추출한다. 형식·용량 검사는 파일을 서버로 보내기 전에 브라우저에서 한다.
- **UPL-06** PPT·hwp 파일을 올리면 PDF로 저장해 올리도록 안내한다. 업로드 영역에 미리 쓰지 않는다(화면 문구 최소화).
- **UPL-07** 추출한 텍스트는 회차 구분([SEC](./session-split))으로 넘긴다.
- **UPL-08** 텍스트 추출에 실패하면 자동으로 한 번 더 시도하고, 그래도 실패하면 안내 문구와 함께 다시 올리게 한다.
- **UPL-09** 올리는 방법은 '파일 올리기'(끌어다 놓기, 파일 고르기)와 '텍스트 붙여넣기' 두 탭으로 나눈다. 기본 탭은 파일 올리기다. (보편 패턴)
- **UPL-10** 파일을 여러 개 한 번에 올리면 한 자료로 묶는다(최대 [N개: 개발 확인], 합계 20MB). 회차를 파일마다 나눌지는 SEC-17에서 고른다. 붙여넣기는 한 번에 하나다. (11/25 팀원 피드백)
- **UPL-11** 자료 이름은 파일 이름(확장자 제외)을 기본으로 쓴다. 붙여넣은 텍스트는 첫 줄 앞 30자를 쓴다. 사용자가 회차 나누기 전에 바꿀 수 있다.
- **UPL-12** PDF에서 추출한 글자가 쪽당 평균 [N자: 개발 확인]보다 적으면 스캔 PDF로 보고 UPL-02 안내를 보여 준다.
- **UPL-13** 추출한 텍스트는 줄바꿈·공백을 정리하고, PDF의 쪽마다 반복되는 머리말·쪽 번호 줄을 지운다. 필사·퀴즈는 정리한 텍스트를 원문으로 쓴다.
- **UPL-14** 자료 올리기는 로그인한 사용자만 할 수 있다. 로그인하지 않은 사용자는 샘플 세트로 체험한다(ACC-01).
- **UPL-18** 업로드 화면에 '잘 나오는 자료' 예시 하나를 붙여 둔다(제목과 문단이 나뉜 텍스트). 자료 정리 매뉴얼 전체와 서버가 받을 데이터 형식은 2사이클에 BE와 정한다. (11/25 팀원 피드백)

</div>

### 미결정

<div class="policy">

- **UPL-15** 한 자료의 최대 글자 수. 20MB는 파일 용량 기준이라 텍스트로 수백만 자가 될 수 있음. AI 모델이 한 번에 읽을 수 있는 양에 맞춰 정함 → 4차 회의 AI 모델 결정 후
- **UPL-16** 올린 원본 파일의 보관 여부·기간 (족보 저작권 논의와 함께)

</div>

## 처리 흐름

자료 하나는 아래 상태를 차례로 거칩니다. 화면은 상태에 따라 바뀝니다.

| 순서 | 상태 | 하는 일 | 다음 상태 | 정책 |
| --- | --- | --- | --- | --- |
| 1 | 선택됨 | 브라우저에서 형식·용량 검사 | 통과 → 올리는 중 / 실패 → 선택 전(오류 안내) | UPL-01·02·03·05 |
| 2 | 올리는 중 | 서버로 파일 전송 | 추출 중 | — |
| 3 | 추출 중 | 텍스트 추출, 스캔 PDF 판별, 정리 | 성공 → 회차 나누는 중 / 실패 → 추출 실패 | UPL-08·12·13 |
| 4 | 추출 실패 | 1회 자동 재시도 후에도 실패하면 안내 | 선택 전 | UPL-08 |
| 5 | 회차 나누는 중 | [SEC 처리 흐름](./session-split#처리-흐름)으로 넘어감 | — | UPL-07 |

- 붙여넣은 텍스트는 형식 검사와 추출을 건너뛰고, 정리(UPL-13)만 한 뒤 회차 나누기로 넘어갑니다.

## 예외·에러 메시지

| 상황 | 메시지 (초안, 제목 / 본문) | 정책 |
| --- | --- | --- |
| 20MB 초과 | 파일이 너무 커요 / 한 번에 20MB까지 올릴 수 있어요. | UPL-03 |
| 받지 않는 형식 | 이 형식은 올릴 수 없어요 / txt·md·docx 파일과 글자로 된 PDF만 올릴 수 있어요. | UPL-01·02 |
| PPT 파일 | PPT는 바로 올릴 수 없어요 / PDF로 저장한 뒤 올려 주세요. | UPL-06 |
| hwp·hwpx 파일 | 한글(hwp) 파일은 바로 올릴 수 없어요 / PDF로 저장한 뒤 올려 주세요. | UPL-06·17 |
| 글자가 추출되지 않는 PDF | 스캔한 PDF는 아직 올릴 수 없어요 / 글자로 된 PDF를 올려 주세요. | UPL-02·12 |
| 파일 여러 개 | (오류 아님) 파일 n개를 한 자료로 묶어요. 회차를 파일마다 나눌 수 있어요. | UPL-10, SEC-17 |
| 추출 실패 | 글자를 읽지 못했어요 / 파일을 다시 올려 주세요. | UPL-08 |
| 붙여넣은 텍스트가 없음 | (버튼 비활성, 메시지 없음) | UPL-09 |
