# 위키 읽는 법

이 위키는 PM이 따닥의 기획 의도, 정책, 동작 규칙을 정리하는 곳입니다. 개발과 디자인은 이 위키를 기준으로 진행합니다.

## 보기 전환

- 버전은 하나이고, 같은 내용을 두 가지로 표현합니다.
- 각 페이지 위의 **보기** 버튼으로 바꿉니다. 고른 보기는 다음 방문에도 유지되고, 링크에 `?view=design`을 붙이면 디자이너용으로 열립니다.

| 보기 | 표현 방식 | 담는 내용 |
| --- | --- | --- |
| 개발자용 | 텍스트 | 기획 의도, 정책, 동작 규칙, 예외 처리 |
| 디자이너용 | 와이어프레임 + 화면 설계서 | 사용자 흐름, 화면 요소별 액션·상태, 애니메이션(Claude 아티팩트) |

::: dev
지금은 **개발자용** 보기입니다. 의도와 규칙을 개발할 수 있을 만큼 구체적으로 적습니다. 문장이 두 가지로 읽히면 질문으로 남겨 주세요.
:::

::: design
지금은 **디자이너용** 보기입니다. 화면마다 요소, 액션, 상태를 표로 적고, 움직임은 Claude 아티팩트 링크로 보여 줍니다.
:::

## 상태 표시

| 표시 | 뜻 |
| --- | --- |
| <Status type="확정" /> | 회의에서 정한 내용. 바꾸려면 회의에서 다시 정함 |

## 질문·피드백

- 방법은 4차 회의(11/24(화))에서 정합니다. <Status type="미결정" />
- 그 전까지는 [GitHub 이슈](https://github.com/soohy00/ttadak-wiki/issues)에 남겨 주세요.

## 기준 문서

- 회의 기록과 사전 의견은 팀 노션(WEB 1팀 > 회의 로그)에 있습니다. 위키에는 결정된 내용과 그 결정의 이유만 옮깁니다.
