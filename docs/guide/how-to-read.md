# 위키 읽는 법

이 위키는 PM이 따닥의 기획 의도와 정책을 정리하는 곳입니다. 개발과 디자인은 이 위키를 기준으로 진행합니다.

## 문서 종류

버전은 하나입니다. **정책서**가 원본이고, **화면 설계서**는 같은 정책을 화면으로 보여 줍니다.

| 문서 | 먼저 읽는 사람 | 담는 내용 |
| --- | --- | --- |
| 정책서 | 전원 (개발자는 이 문서를 기준으로 개발) | 목적, 용어, 번호 붙은 정책, 예외·에러 메시지, 변경 이력 |
| 화면 설계서 | 디자이너 (개발자도 참고) | 사용자 흐름, 화면별 와이어프레임, 번호별 요소·액션·상태, 애니메이션 |

- **레이아웃은 확정이 아닙니다.** 화면 설계서의 배치는 흔한 레퍼런스 사례를 참고한 것이고, 따닥에 가장 맞아서 고른 것이 아닙니다. 기능과 동작(정책)은 따르되, 레이아웃과 비주얼은 디자인에서 새로 정해 주세요. 시안에 없는 레이아웃을 제안해도 됩니다. (4차 회의)

## 정책 번호

- 기능마다 세 글자 ID를 붙입니다: UPL(업로드), SEC(회차 구분), TRN(필사), QIZ(퀴즈), ACC(계정·설정)
- 정책은 `UPL-01`처럼 번호로 부릅니다. PR·이슈·회의에서 "UPL-03 기준"처럼 번호로 이야기해 주세요.
- 화면은 `SCR-UPL-01`처럼 부르고, 화면 설명 표의 "정책" 칸이 정책 번호와 이어집니다.
- 한 번 붙인 번호는 바꾸지 않습니다. 정책이 없어지면 번호를 지우지 않고 "폐기"로 표시합니다.

## 정책 상태

정책서의 정책은 세 묶음으로 나눕니다.

| 묶음 | 뜻 |
| --- | --- |
| 확정 | 회의에서 정한 내용. 바꾸려면 회의에서 다시 정함 |
| 검토 중 | PM 초안이나 팀원 제안. 검토 의견을 받고 있음 |
| 미결정 | 아직 정하지 않음. 정할 회의나 방법을 함께 적음 |
